# 利用者月間生活カレンダー 試用の手順(1台のパソコン用)

この手順は、事務所のパソコン1台で、利用者1人分から試すためのものです。氏名はそのパソコンのブラウザの中だけに保存され、インターネットには送られません。

## 1. 準備(5分)

1. 「利用者月間生活カレンダー.html」を、パソコンの決まった場所(例: ドキュメントの中の専用フォルダ)に保存します。
2. Google Chrome か Microsoft Edge で開きます(ファイルを右クリックして「プログラムから開く」で選びます)。
3. 毎回、同じブラウザで、同じ場所のファイルを開きます。別のブラウザや、別の場所にコピーしたファイルを開くと、入力した内容が見えません。
4. 画面の上に「このブラウザでは入力した内容を保存できません」と出たときは、プライベートウィンドウではなく、通常のウィンドウで開き直してください。

## 2. 1人分を入力する(目安20分)

1. 名簿タブ
   - Excelの名簿表で、試す1人の「ホーム」と「氏名」の2つのセルをコピーして貼り付けます。
   - 「いまの利用者(サンプル含む)…置き換える」にチェックが入っていることを確認し、「内容を確認」→「この内容で取り込む」を押します。サンプルの利用者と通所先が消えます。
2. 通所先・休業日タブ
   - 「通所先を追加」に、実際の通所先の名前を入れて追加します。
   - 休みの曜日と、祝日休みの有無を、実際に合わせます。
   - 年末年始など、独自の休業日を追加します(例: 1月1日から1月3日まで「年始休業」)。
3. 固定予定タブ
   - 「固定予定を追加」で、毎月くり返すものを入れます。入れ方の例です。
     - 通所先: 種類「通所」、予定の名前に通所先、通所先を選ぶ、曜日(月〜金など)、時間、「祝日は予定を作らない」にチェック。
     - 土日の帰宅: 種類「帰宅(緑の帯)」、予定の名前「夕方にホームに帰宅」、曜日は土と日。
     - 通院やガイド: 種類を選び、「第2・第4」などの繰り返しと時間、担当者名を入れる。
     - 数日だけの予定(実家泊など): 種類「外泊・実家泊(桃色の帯)」、適用開始日と終了日を入れる。
4. 月間カレンダー
   - 試す月を選び、「この月を自動配置」を押します。
   - 「印刷される文面」に、赤い注意帯と黄色の連絡帯を入れます。
5. 突発的な予定
   - カレンダーの日付を押すと、予定の追加・変更・取消、文字の大きさの変更ができます。

## 3. 現行のExcelと見比べる

次の点を、現行のExcelの同じ月と見比べてください。

- 各日の通所先、帰宅、実家泊が同じ場所に出ているか
- 祝日と、通所先の休みの日が同じか
- 赤い帯と黄色の帯の文面が同じか
- 「A4の印刷プレビュー」をオンにして、1枚に収まり、文字が読めるか
- 違うところは、メモして伝えてください。

## 4. 印刷

1. 印刷タブで、ホームと用紙の形(カレンダーはA4横、一覧はA4縦)を選びます。
2. 印刷する人にチェックを入れ、「印刷する」を押します。
3. 印刷の設定は、「倍率: 100%」「背景のグラフィック: オン」にします。オフだと、色の帯が印刷されません。

## 5. 保存と注意

- 入力するたびに、このパソコンのブラウザに自動で保存されます。
- ブラウザの閲覧データ(サイトデータ)を消すと、入力した内容も消えます。
- 名簿タブの「バックアップをコピー」で、内容を文字として取り出せます。メモ帳に貼り付けて、週に1回は保管してください。戻すときは、同じ画面の「この内容に戻す」に貼り付けます。
- 複数のパソコンで同じ内容を使うことはできません(パソコンごとに別々になります)。複数人での利用、ログイン、操作履歴は、本番版で対応します。
- 現行のExcelは、試用のあいだ削除せずに残してください。
