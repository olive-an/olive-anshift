# 検証キットの使い方 (約10分)

目的 個人Gmailで、ログイン、非公開保存、OCRが実際に動くかを確認します。名刺データは使いません。

## 手順
1. 名刺専用にするGoogleアカウントで script.google.com を開き、新しいプロジェクトを作る。
2. Code.gs の中身を、このフォルダの Code.gs に置き換える。
3. 左の「ファイル」の追加でHTMLを選び、名前を verify にして、verify.html の中身を貼る。
4. 右上「デプロイ」から「新しいデプロイ」を選び、種類はウェブアプリ。
   - 次のユーザーとして実行 : ウェブアプリにアクセスしているユーザー
   - アクセスできるユーザー : Googleアカウントを持つ全員
5. 発行されたURLを、別の @gmail.com の従業員のスマホで開き、承認画面を進める。
6. ページの各ボタンを押して、結果を画面メモか写真で共有する。名刺の写真は、練習用に自分の名刺か、許可を得た名刺を使う。
