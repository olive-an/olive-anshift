# 監査勤務形態一覧　６ブック統合ツール

`▲監査勤務形態一覧▲` フォルダにある事業所別の「２０２６０１～のシフト管理表(事業所).xlsx」６ファイルを、
**１つのブックに統合**します。

統合順（固定）：

1. 西九条
2. 九条
3. 酉島
4. 新郡山
5. 春日出
6. 出来島

## 特徴

Excel 本体のシートコピー機能を使うため、**元の見た目がそのまま残ります**。

- 夜勤の黄色塗り・セル色
- 罫線・フォント・列幅・行高
- 数式（`合計` 列の SUM など）
- 印刷範囲・ページ設定

各ブックの `様式 (事業所名○○)202601`〜`202612` の12ヶ月分シートが、上記の順番で並びます。
先頭には各シートへのリンク付き **目次シート** が付きます。

## 使い方

1. 共有フォルダ `\\192.168.10.100\iwakubo\...` に接続できる状態にする
2. このフォルダの **`統合実行.bat` をダブルクリック**
3. 処理が終わると、元フォルダに `統合_監査勤務形態一覧_yyyyMMdd_HHmm.xlsx` ができます

処理中は Excel が裏で動きます。**他の Excel ファイルは閉じてから**実行してください。
６ブック分（約 8MB）を開くため、1〜3 分ほどかかります。

## オプション付きで実行する場合

PowerShell から直接呼びます。

```powershell
# 別のフォルダのファイルを統合する
.\Merge-ShiftWorkbooks.ps1 -Root "D:\作業用\監査資料"

# 出力先とファイル名を指定する
.\Merge-ShiftWorkbooks.ps1 -OutFile "D:\提出用\勤務形態一覧_統合.xlsx"

# 統合順を変える
.\Merge-ShiftWorkbooks.ps1 -Order '九条','西九条','酉島','新郡山','春日出','出来島'

# 目次シートを作らない
.\Merge-ShiftWorkbooks.ps1 -NoIndexSheet

# 統合後、保存した状態で Excel を開いたままにする（中身をすぐ確認したいとき）
.\Merge-ShiftWorkbooks.ps1 -KeepExcelOpen
```

| パラメータ | 既定値 | 説明 |
| --- | --- | --- |
| `-Root` | `\\192.168.10.100\iwakubo\指導監査用\▲監査勤務形態一覧▲` | 元ファイルのフォルダ |
| `-OutFile` | `<Root>\統合_監査勤務形態一覧_yyyyMMdd_HHmm.xlsx` | 出力先 |
| `-Order` | 西九条, 九条, 酉島, 新郡山, 春日出, 出来島 | 統合順 |
| `-SkipSheets` | `Sheet1` | 取り込まないシート名 |
| `-NoIndexSheet` | － | 目次シートを作らない |
| `-KeepExcelOpen` | － | 終了後も Excel を開いたままにする |
| `-Force` | － | 出力先が既にある場合に上書きする |

出力先が既に存在する場合は、事故防止のためエラーで止まります。
上書きしてよいときだけ `-Force` を付けてください。

### `Sheet1` を既定で除外している理由

各ブックの `Sheet1` は索引用シートですが、ブックを複製して作られたため
**中身が他事業所（西九条）のシート名のまま**で、リンク先も実在しません。
そのまま統合すると誤解を招くので除外し、代わりに正しい目次シートを新規作成しています。

取り込みたい場合は `-SkipSheets @()` を指定してください。

## ファイルの特定方法

事業所名は**括弧で囲まれた形**でのみ一致させています（例：`シフト管理表(九条).xlsx`）。
単純な部分一致だと「九条」が「西九条」にも当たってしまうためです。
半角 `()` と全角 `（）` の両方に対応しています。

一致するファイルが 0 件・2 件以上の場合はエラーで止まり、上書き事故を防ぎます。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| `フォルダにアクセスできません` | 共有フォルダに接続できているか、エクスプローラで確認 |
| `「○○」のファイルが見つかりません` | ファイル名に `(事業所名)` が入っているか確認 |
| `一致するファイルが複数あります` | バックアップ等の重複ファイルを別フォルダへ移動 |
| `出力先が既に存在します` | `-Force` を付けるか、`-OutFile` で別名を指定 |
| Excel が残ってしまった | タスクマネージャーで `Excel` を終了 |
| 外部リンクの警告が出た | 元ファイルを移動・削除しなければ問題ありません |

## 動作環境

- Windows + デスクトップ版 Excel（COM 自動化を使用）
- Windows PowerShell 5.1 以上

スクリプトは UTF-8 (BOM 付き) で保存されています。編集する際は BOM を消さないでください。
